## 在线预览

[点击访问](https://zhangjign.github.io/my-first-page/)

## 本地打开方式

1. 克隆仓库：`git clone https://github.com/zhangjign/my-first-page.git`
2. 用VS Code 打开文件夹
3. 安装Live Server 插件，右键 index.html -> Open with Live Server
